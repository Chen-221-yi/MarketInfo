# 市场信息管理系统普通用户操作使用手册

## 一、手册说明

### 1.1 编写目的

本手册用于指导普通用户使用市场信息管理系统，完成单位档案、联系人、拜访记录、项目档案等市场信息的日常录入、查询、查看和维护。

### 1.2 适用对象

本手册适用于普通用户、市场人员、项目跟进人员、业务人员等需要录入、查询和维护市场信息的人员。

### 1.3 普通用户可使用功能范围

本手册只覆盖以下菜单模块：

* 首页总览
* 联系人管理
* 拜访记录
* 项目管理
* 单位档案

如页面出现其他菜单、维护入口或配置入口，不属于本手册范围，按公司管理要求和实际页面权限使用。

### 1.4 使用原则

* 谁跟进，谁维护。
* 新增前先查询，避免重复录入。
* 信息变更后及时更新。
* 拜访记录应真实、完整、可追溯。
* 项目状态和项目阶段应随实际进展及时维护。
* 联系人、单位、拜访记录、项目之间尽量建立关联。

## 二、系统登录与通用操作

### 2.1 进入系统

用户可从钉钉 / 宜搭入口进入市场信息管理系统。进入后，按页面左侧或顶部菜单进入对应模块。

如果页面提示暂无查看权限，说明当前账号只能使用部分入口或提交类功能，请以实际页面显示为准。

### 2.2 系统菜单说明

本手册涉及的菜单如下：

* 首页总览：查看关键数据、近期动态、待关注事项和快捷入口。
* 联系人管理：查询、查看、新增和维护联系人信息。
* 拜访记录：记录并查看客户拜访、沟通和后续事项。
* 项目管理：维护项目档案、项目阶段、项目状态和项目联系人。
* 单位档案：维护客户单位、政府部门、合作单位等基础信息。

### 2.3 通用页面结构

系统页面通常包含：

* 查询筛选区：按关键词、状态、分类、时间等条件筛选数据。
* 数据列表区：展示符合条件的记录。
* 操作按钮区：提供新增、详情、编辑、记录拜访等操作。
* 详情查看区：展示单条记录的完整信息和关联信息。
* 新增 / 编辑表单区：录入或修改业务数据。

### 2.4 通用查询操作

1. 进入对应菜单。
2. 在搜索框输入关键词，例如联系人姓名、单位名称、项目名称、地区、岗位、拜访标题等。
3. 按页面提供的筛选条件进一步缩小范围，例如状态、星级、阶段、拜访方式、单位类型、所属系统等。
4. 如需恢复全部数据，点击“重置”或清除搜索框内容。

### 2.5 通用新增操作

1. 在对应页面点击“新增联系人”“记录拜访”“新增项目”或“新增单位”等按钮。
2. 按表单提示填写必需信息和已掌握信息。
3. 尽量选择关联的单位、联系人或项目。
4. 检查无误后提交保存。

### 2.6 通用编辑操作

1. 在列表中点击记录或点击“详情”进入详情页。
2. 如详情页提供“编辑”按钮，点击后进入编辑页面。
3. 修改变化的信息，例如联系方式、职务、项目状态、下一步动作等。
4. 保存后返回列表或详情页查看更新结果。

### 2.7 通用查看详情操作

1. 在列表中点击记录行或点击“详情”。
2. 在详情页查看基础信息、关联数据和历史记录。
3. 如详情页有页签，可切换查看联系人、项目、拜访记录等关联内容。

### 2.8 通用刷新操作

系统页面会定时刷新数据。若保存后页面没有立即变化，可尝试：

1. 返回列表重新进入。
2. 清除筛选条件后重新查询。
3. 刷新当前页面。
4. 稍后再次查看。

## 三、首页总览

### 3.1 功能说明

首页总览用于帮助用户快速了解市场信息整体情况，包括联系人数量、拜访风险、在推项目、资料完整度、近期拜访、最新动态和项目推进情况。

### 3.2 首页数据概览

首页顶部展示以下数据卡片：

* 联系人总数：展示系统内联系人总数，并显示活跃联系人数量。
* 拜访超期：展示已超期联系人数量，并显示即将超期数量。
* 在推项目：展示在推项目数量，并显示关键关系数量。
* 资料不足：展示资料完整度低于 80% 的联系人数量。

点击数据卡片可进入对应列表或筛选结果，例如联系人列表、拜访超期联系人、项目管理、资料不足联系人等。

### 3.3 首页最新动态

首页“最新动态”区域展示近期发生的业务变化，包括：

* 拜访记录新增或更新。
* 项目更新。
* 项目联系人关系变化。

用户可点击动态项进入对应详情。页面中有“标记已读”按钮，用于标记当前动态已读。

### 3.4 首页待处理事项

首页包含以下待关注内容：

* 拜访超期 / 即将超期：提示需要尽快跟进的联系人。
* 近期重要日期：展示近期需要关注的重要提醒。
* 情报线索：展示待关注的线索信息。
* 资料完整度待提升：提示资料不完整的联系人。

用户每天进入系统后，建议优先查看拜访超期、近期重要日期、资料不足联系人和在推项目。

### 3.5 首页快捷入口

首页已实现的常用快捷按钮包括：

* 新增联系人：进入联系人新增表单。
* 记录拜访：进入拜访记录新增表单。

首页还存在数据维护类入口，该入口不属于普通用户日常操作范围，本手册不展开说明。

### 3.6 点击动态进入详情

1. 在“最新动态”中找到需要查看的记录。
2. 点击动态标题或记录区域。
3. 系统会跳转到对应的拜访记录详情、项目详情或项目管理页面。

### 3.7 每日查看建议

用户每天进入系统后建议按以下顺序查看：

1. 查看是否存在拜访超期或即将超期联系人。
2. 查看近期重要日期和待处理线索。
3. 查看最近拜访记录，确认后续动作是否明确。
4. 查看在推项目，确认项目状态、阶段和下一步计划是否需要更新。
5. 查看资料不足联系人，补充关键资料。

## 四、联系人管理

### 4.1 功能说明

联系人管理用于维护客户联系人、单位人员、项目相关人员等信息。用户可查询联系人，查看联系人详情，新增联系人，维护联系方式、所属单位、岗位职务、标签和关联信息。

### 4.2 联系人列表查看

联系人列表展示以下内容：

* 联系人：姓名、别名、头像标识、主维护人、年龄。
* 单位 / 岗位：岗位职务、所属单位。
* 星级：按 1 至 5 星展示。
* 状态：例如活跃、待维护、暂缓、失联、离退休。
* 最近拜访：展示拜访状态和日期。
* 完整度：展示联系人资料完整度。
* 标签：展示联系人标签。
* 操作：点击“详情”进入联系人详情页。

### 4.3 查询联系人

1. 进入“联系人管理”。
2. 在搜索框输入姓名、别名、单位、岗位或地区。
3. 点击“筛选”，可按以下条件筛选：
   * 状态：活跃、待维护、暂缓、失联、离退休。
   * 星级：5 星、4 星、3 星、2 星、1 星。
   * 快捷筛选：拜访超期、资料不足。
   * 标签：按系统中已有联系人标签筛选。
4. 可使用排序菜单按星级、最近拜访、下次截止或完整度补齐排序。
5. 点击“重置”或“清除筛选”恢复默认列表。

### 4.4 新增联系人

1. 在联系人管理页面点击“新增联系人”。
2. 按新增表单填写联系人信息。
3. 当前页面可确认的联系人字段包括：
   * 姓名、别名、性别、出生日期。
   * 客户星级、客户类型、客户状态、关系阶段。
   * 所属单位、当前部门、岗位 / 职务、职级 / 级别、分管业务、所属地区。
   * 工作电话、手机号、微信号、办公地点。
   * 标签、熟悉同事、主维护人 / 建档人。
   * 最近拜访、下次截止、拜访状态。
   * 保密设置、信息来源、备注。
4. 新增联系人时应尽量选择所属单位，便于后续在单位档案、拜访记录和项目中关联。

新增表单的必填项、选项内容和提交校验以实际页面显示为准。

### 4.5 编辑联系人

当联系人职务、联系方式、所属单位、标签或维护信息发生变化时，应及时编辑联系人。

1. 在联系人列表点击“详情”。
2. 在联系人详情页点击“编辑”。
3. 修改需要更新的字段。
4. 保存后返回详情页或列表确认。

如果当前账号进入详情页后未显示“编辑”按钮，请以实际页面权限为准。

### 4.6 查看联系人详情

联系人详情页可查看：

* 基础信息：联系人编号、姓名、别名、性别、出生日期、年龄、客户类型、所属地区。
* 当前岗位：当前单位、当前部门、岗位职务、职级、分管业务。
* 联系方式：工作电话、手机号、微信号、办公地点。
* 拜访状态：最近拜访、下次截止、超期状态、关系阶段。
* 维护信息：主维护人、熟悉同事、建档人、建档时间、最近更新、维护贡献。
* 标签信息：已有标签，可通过“管理标签”维护。
* 关联信息：任职履历、相册、私密画像、社会关系、拜访记录、关联项目、重要日期、情报线索等页签。

部分页签或详情内容可能受账号可见范围影响，以实际页面显示为准。

### 4.7 联系方式维护

联系方式包括工作电话、手机号、微信号、办公地点等。维护要求如下：

1. 已确认的信息应及时填写。
2. 号码变更后应及时更新。
3. 不确定的信息不要随意填写，可在备注或信息来源中说明。
4. 至少维护一种可联系渠道，便于后续拜访和项目跟进。

### 4.8 拥有微信的同事

当前联系人详情页已实现“熟悉同事 / 我有他的微信”功能。

* 在联系人详情的“维护信息”中查看“熟悉同事”。
* 如果当前用户拥有该联系人微信，可点击“我有他的微信”。
* 点击后，当前用户会加入熟悉同事列表，并显示“已认领”。
* 如果不再适合标记，可点击“取消认领”移除自己。
* 该功能仅用于内部协作，不代表联系人归属。

### 4.9 联系人关联信息查看

联系人详情可查看或进入以下关联信息：

* 所属单位：在基础信息或当前岗位中查看。
* 拜访记录：在“拜访记录”页签查看与该联系人关联的拜访记录。
* 关联项目：在“关联项目”页签查看该联系人参与或关联的项目。
* 重要日期：查看出生日期、最近拜访、下次拜访截止和提醒。
* 情报线索：查看或新增与联系人相关的线索。

如当前账号仅显示新增入口，不显示已有记录，请以实际页面显示为准。

### 4.10 联系人维护注意事项

* 新增前先查询，避免重复联系人。
* 姓名、单位、岗位相近时，应进入详情核对后再判断是否新增。
* 联系方式变更后及时维护。
* 联系人应尽量关联单位。
* 与项目有关的联系人应及时关联项目。
* 标签应简洁准确，不要重复创建含义相同的标签。

## 五、拜访记录

### 5.1 功能说明

拜访记录用于记录市场人员与客户单位、联系人之间的沟通情况，沉淀拜访时间、方式、地点、交流内容、后续动作和关联项目。

### 5.2 拜访记录列表查看

拜访记录列表以卡片形式展示：

* 拜访方式。
* 拜访标题。
* 关联项目。
* 关联单位。
* 主联系人。
* 我方参与人或记录人。
* 拜访地点。
* 拜访日期。
* 内容摘要。
* 后续动作和计划日期。
* 详情入口。

### 5.3 查询拜访记录

1. 进入“拜访记录”。
2. 在搜索框输入拜访标题、联系人、摘要、参与人等关键词。
3. 可按拜访方式筛选：
   * 上门
   * 电话
   * 饭局
   * 会议
   * 培训会
   * 活动
   * 微信
4. 点击“重置”恢复默认列表。

### 5.4 新增拜访记录

1. 点击“记录拜访”。
2. 按表单填写拜访记录。
3. 当前页面可确认的拜访记录字段包括：
   * 拜访标题。
   * 主联系人。
   * 关联单位。
   * 关联项目。
   * 我方参与人。
   * 拜访方式。
   * 拜访时间。
   * 拜访地点。
   * 交流内容。
   * 后续动作。
   * 下次跟进日期。
   * 授权查看人。
   * 附件。
   * 记录人、记录时间。
4. 保存前应确认联系人、单位和项目关联是否准确。

新增表单的必填项和选项以实际页面显示为准。

### 5.5 编辑拜访记录

当拜访内容需要补充、后续事项需要调整、附件需要补充时，可进入拜访详情页点击“编辑”。

1. 在拜访列表点击记录或“详情”。
2. 在详情页点击“编辑”。
3. 修改交流内容、后续动作、下次跟进日期、附件等信息。
4. 保存后返回详情页查看。

如果当前账号不显示详情或编辑入口，请以实际页面显示为准。

### 5.6 查看拜访详情

拜访详情页可查看：

* 拜访标题、拜访方式、拜访日期、地点、我方参与人。
* 主联系人、关联单位、关联项目。
* 计划跟进日期。
* 交流内容。
* 后续动作。
* 授权查看人。
* 附件。
* 由拜访生成或关联的情报线索。

详情页支持点击主联系人、关联单位、关联项目进入对应详情。

### 5.7 拜访记录与联系人关联

填写拜访记录时，应选择对应主联系人。若一次拜访涉及多人，应至少选择主要沟通对象，并在交流内容中补充其他参与人。

### 5.8 拜访记录与单位关联

拜访记录应关联对应单位。若从联系人详情或项目详情发起记录拜访，页面会尽量带入联系人或单位信息，仍需提交前检查。

### 5.9 拜访记录与项目关联

当前系统支持拜访记录关联项目。新增拜访记录时可选择关联项目；在项目详情中点击“记录拜访”时，系统会带入项目和单位信息。

### 5.10 拜访记录填写规范

拜访记录应写清：

* 拜访时间。
* 拜访对象。
* 沟通背景。
* 客户需求。
* 沟通结果。
* 下一步计划。
* 责任人和时间节点。
* 附件资料。

错误示例：

> 已拜访，后续继续跟进。

推荐示例：

> 今日与 XX 单位 XX 负责人沟通项目推进情况。客户重点关注预算安排、实施周期和服务保障。已向客户说明初步方案，客户建议下周补充技术参数和类似案例。后续由张三负责在 6 月 28 日前整理材料并再次沟通。

## 六、项目管理

### 6.1 功能说明

项目管理用于维护市场项目、跟进项目、潜在项目等信息，记录项目阶段、状态、负责人、关键联系人、风险卡点和下一步动作。

### 6.2 项目列表查看

项目列表以卡片形式展示：

* 项目名称。
* 项目阶段。
* 项目状态。
* 所属单位。
* 所属地区。
* 项目类型。
* 项目负责人。
* 最近更新日期。
* 项目星级。
* 项目摘要、关键进展或最新进展。
* 关键联系人。
* 风险 / 卡点。
* 下一步动作、下一步负责人、计划日期。
* 详情入口。

### 6.3 查询项目

1. 进入“项目管理”。
2. 在搜索框输入项目名称、地区、负责人等关键词。
3. 可按项目阶段筛选：
   * 线索
   * 接洽
   * 方案
   * 推进
   * 招采
   * 实施
   * 验收
   * 归档
4. 可按项目状态筛选：
   * 正常
   * 重点推进
   * 有风险
   * 暂停
   * 归档
5. 点击“重置”恢复默认查询。

当前系统保留项目星级和排序相关信息，但项目管理页面筛选区主要展示阶段和状态筛选；其他筛选或排序以实际页面显示为准。

### 6.4 新增项目

1. 在项目管理页面点击“新增项目”。
2. 按表单填写项目资料。
3. 当前页面可确认的项目字段包括：
   * 项目编号、项目名称、项目简称。
   * 所属地区、所属单位。
   * 项目类型、项目阶段、项目星级、项目状态。
   * 项目负责人、项目成员、授权查看人。
   * 项目摘要、关键推进信息、决策链说明。
   * 风险点、当前卡点。
   * 下一步动作、下一步负责人、计划日期。
   * 最新进展、最新进展日期。
   * 备注。
4. 新增前应先查询是否已有同名或相近项目，避免重复。

新增表单的必填项和选项以实际页面显示为准。

### 6.5 编辑项目

当项目负责人、项目状态、项目阶段、关键联系人、项目说明、风险卡点或下一步计划发生变化时，应及时编辑。

1. 在项目列表点击项目卡片或“详情”。
2. 在项目详情页点击“编辑”。
3. 更新变化的信息。
4. 保存后返回项目详情页确认。

### 6.6 查看项目详情

项目详情页可查看：

* 项目名称、项目简称、项目阶段、项目状态、项目类型。
* 所属单位、所属地区、项目负责人、项目星级、项目编号。
* 关联联系人数量、拜访记录数量、下一步动作。
* 项目摘要。
* 最新进展。
* 关键推进信息。
* 决策链说明。
* 风险点、当前卡点。
* 下一步动作、负责人和计划日期。
* 关键联系人、联系人变更、拜访记录等页签。

### 6.7 项目状态维护

当前系统可识别的项目状态包括：

* 正常：项目按计划推进。
* 重点推进：项目需要重点关注和推进。
* 有风险：项目存在风险，需要重点跟踪。
* 暂停：项目暂时停止推进。
* 归档：项目已结束或暂不继续跟进。

维护状态时，应以项目真实进展为准。如表单内出现其他状态，以系统实际选项为准。

### 6.8 项目阶段维护

当前系统可识别的项目阶段包括：

* 线索：仅形成初步机会或信息。
* 接洽：已开始接触客户或相关方。
* 方案：正在准备或沟通方案。
* 推进：项目持续推进中。
* 招采：进入招采或相关关键节点。
* 实施：项目进入实施阶段。
* 验收：项目进入验收阶段。
* 归档：项目已归档或不再推进。

如表单内出现其他阶段，以系统实际选项为准。

### 6.9 项目联系人维护

项目详情页“关键联系人”页签展示项目相关联系人，可查看：

* 联系人姓名。
* 当前岗位和单位。
* 项目角色。
* 影响程度。
* 熟悉程度。
* 我方熟悉人。
* 关系状态。
* 生效日期。
* 关键诉求。
* 维护策略。
* 下一步动作。

在“关键联系人”页签点击“关联联系人”可新增项目联系人关系。

### 6.10 项目联系人变更

当前项目详情页已实现联系人变更记录查看和维护入口。

* 新增项目联系人：在“关键联系人”或“联系人变更”页签点击“关联联系人”。
* 结束联系人关系：进入对应联系人关系记录后编辑关系状态、结束日期和变更说明。
* 查看历史联系人：进入“联系人变更”页签查看关系状态、生效日期、结束日期、变更说明、记录人和记录时间。
* 当前联系人：关系状态为空或为“当前”的联系人会作为当前关键联系人展示。
* 历史联系人：关系状态为已结束或填写结束日期的记录，用于保留变更过程。
* 生效日期：记录该联系人关系开始生效的日期。
* 结束日期：记录该联系人关系结束的日期。
* 变更说明：说明新增、调整或结束关系的原因。

具体状态选项以实际表单显示为准。

### 6.11 项目关联拜访记录

当前系统支持在项目详情中查看关联拜访记录。

* 在项目详情页切换到“拜访记录”页签，可查看与该项目关联的拜访记录。
* 点击拜访记录可进入拜访详情。
* 点击“记录拜访”可新增与该项目关联的拜访记录。

### 6.12 项目维护注意事项

* 项目名称应清晰，避免简称过短导致无法识别。
* 所属单位应准确。
* 项目负责人应明确。
* 项目状态和项目阶段应及时更新。
* 关键联系人应尽量准确维护。
* 重要沟通应通过拜访记录沉淀。
* 避免重复新增同一项目。

## 八、普通用户日常使用流程

### 8.1 新客户信息录入流程

单位档案查询 → 新增单位 → 联系人查询 → 新增联系人 → 新增拜访记录 → 如形成项目机会则新增项目。

操作建议：

1. 先查单位是否已存在。
2. 单位不存在时新增单位。
3. 再查联系人是否已存在。
4. 联系人不存在时新增联系人，并关联单位。
5. 拜访后新增拜访记录，并关联单位和联系人。
6. 如形成项目机会，新增项目并关联单位。

### 8.2 日常拜访记录流程

进入拜访记录 → 新增 → 选择单位和联系人 → 填写内容和后续事项 → 关联项目 → 保存。

如从联系人详情或项目详情发起记录拜访，系统可能带入部分关联信息，保存前仍需检查。

### 8.3 项目跟进维护流程

进入项目管理 → 查询项目 → 查看详情 → 更新状态或阶段 → 维护关键联系人 → 关联拜访记录。

维护重点：

* 最新进展是否及时填写。
* 下一步动作是否清晰。
* 负责人和计划日期是否明确。
* 风险点和卡点是否需要更新。

### 8.4 查看某单位完整信息流程

进入单位档案 → 查询单位 → 查看详情 → 查看联系人、拜访记录、项目。

### 8.5 查看某联系人完整信息流程

进入联系人管理 → 查询联系人 → 查看详情 → 查看联系方式、单位、拜访记录、关联项目。

### 8.6 查看某项目完整信息流程

进入项目管理 → 查询项目 → 查看详情 → 查看状态、阶段、负责人、联系人、拜访记录。

## 九、常见问题

### 9.1 找不到联系人怎么办？

先换关键词查询，例如姓名、别名、单位、岗位。仍找不到时，再确认是否需要新增联系人。新增前应确认不是重名或单位名称不同导致未查到。

### 9.2 找不到单位怎么办？

先用单位全称、简称、所属系统、地区查询。仍找不到时，可新增单位。新增时尽量使用正式全称。

### 9.3 找不到项目怎么办？

先用项目名称、简称、所属单位、负责人查询。仍找不到时，再确认是否需要新增项目，避免重复建档。

### 9.4 数据保存后页面没有变化怎么办？

可返回列表重新进入、清除筛选后再查，或刷新页面。若仍未显示，稍后再查看或联系系统负责人确认。

### 9.5 联系人重复了怎么办？

不要继续维护重复记录。先确认哪条信息更完整，再联系系统负责人或数据维护人员处理合并或清理。

### 9.6 单位重复了怎么办？

停止继续新增相关联系人或项目到重复单位下。先确认正式单位名称，再联系系统负责人或数据维护人员处理。

### 9.7 项目状态不知道怎么选怎么办？

按项目真实进展选择。无法判断时，先查看项目阶段、最近进展和下一步动作，必要时与项目负责人确认。状态选项以系统实际显示为准。

### 9.8 拜访记录写错了怎么办？

进入拜访详情，如页面提供“编辑”按钮，可修改后保存。若当前账号无法编辑，请联系有权限的负责人处理。

### 9.9 页面按钮点击后没有反应怎么办？

先确认当前页面是否加载完成，再刷新页面重试。若页面提示无权限或按钮仍无反应，请按实际页面提示联系系统负责人。

## 十、数据填写规范

### 10.1 联系人填写规范

* 姓名填写真实姓名，别名可填写常用称呼。
* 所属单位尽量选择已有单位。
* 岗位、部门、职级应按当前实际情况填写。
* 电话、手机号、微信号等联系方式应准确。
* 客户状态、星级、关系阶段应按实际了解情况维护。
* 信息来源、备注可记录信息出处和特殊说明。

### 10.2 单位填写规范

* 单位名称尽量使用正式全称。
* 单位简称应便于识别。
* 所属系统、单位类型、单位级别按实际情况选择。
* 所属地区和办公地址尽量填写完整。
* 业务范围填写与公司业务相关的主要职责或合作方向。

### 10.3 拜访记录填写规范

* 拜访时间、拜访方式、拜访地点应准确。
* 主联系人、关联单位、关联项目应尽量选择。
* 交流内容要写清背景、需求、沟通结果。
* 后续动作要明确责任人、事项和时间节点。
* 有会议纪要、照片、材料等资料时可上传附件。

### 10.4 项目填写规范

* 项目名称应清晰完整。
* 所属单位必须准确。
* 项目负责人应明确。
* 项目阶段和状态应及时维护。
* 项目摘要、关键推进信息、最新进展应便于其他同事了解情况。
* 风险点和当前卡点应真实记录。
* 下一步动作应可执行、可跟踪。

### 10.5 数据关联规范

* 联系人应关联单位。
* 拜访记录应关联单位和联系人。
* 项目应关联单位。
* 项目应维护关键联系人。
* 与项目有关的拜访记录应关联项目。
* 从联系人或项目详情发起新增时，应检查系统带入的信息是否正确。
