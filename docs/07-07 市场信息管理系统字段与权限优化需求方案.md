# 07-07 市场信息管理系统字段与权限优化需求方案

## 1. 已确认需求

- `客户星级` 仅调整显示名称为 `客户职务`，选项仍保留 `5星/4星/3星/2星/1星`。
- 联系人主表新增 `是否抽烟`、`是否喝酒`，选项为 `是/否/不确定`。
- `客户状态` 继续显示，默认值为 `活跃`，并新增 `长期未联系`。
- 联系人列表默认只显示有效联系人：`活跃`、`待维护`、`长期未联系`。
- `失联`、`离退休`、`无效` 默认不突出展示，可通过筛选查看。
- 半年未联系的联系人由宜搭定时自动化把状态改为 `长期未联系`。
- 普通员工可在列表看到四星/五星联系人基础摘要，但不能打开联系人详情。
- 权限判断以宜搭角色为主，角色已在后台新建。
- 原生表单删除权限由后台手动配置，代码侧不处理原生删除权限。

## 4. 权限规则

| 角色 | 可见范围 | 可操作 | 不可操作 | 实现方式 |
| -- | -- | -- | -- | -- |
| 高层：总经办 | 全量联系人、线索、拜访、项目、敏感信息 | 新增、维护、修改；进入系统配置/维护入口 | 普通业务删除仍按后台权限控制 | 宜搭角色 + 页面角色判断 + 后台权限 |
| 管理层：规划一部、规划二部、规划三部、工程部部门经理 | 本部门及本人相关数据，联系人完整详情 | 新增、维护、修改 | 不进入系统配置/清空数据入口 | 宜搭角色 + 页面角色判断 + 后台数据权限 |
| 普通员工：规划一部、规划二部、规划三部、工程部普通成员 | 自己创建、负责、经办、关注、必看的数据；联系人列表基础摘要 | 新增联系人、记录拜访、新增线索、维护自己相关数据 | 不看全量线索管理；不打开四/五星联系人详情；不看敏感详情 | 宜搭角色 + 页面入口隐藏/拦截 + 后台导航/数据权限 |

## 5. 定时自动化规则

建议在宜搭后台配置每日定时任务：

1. 查询联系人主表中 `客户状态` 为 `活跃` 或 `待维护` 的联系人。
2. 判断最近拜访时间早于当前日期 180 天，或无最近拜访且创建时间早于 180 天。
3. 将 `客户状态` 更新为 `长期未联系`。
4. 不自动修改 `失联`、`离退休`、`无效` 等人工判定状态。

该规则会改变业务数据，建议先在后台用小范围样本验证，再开启全量定时执行。

## 6. 验收标准

- 新建联系人表单中显示 `客户职务`，选项仍是 `1-5星`。
- 手机号位于姓名后，非必填。
- `是否抽烟`、`是否喝酒` 出现在联系人主表新增表单中，选项为 `是/否/不确定`。
- 私密画像原生表单中的旧 `是否抽烟`、`是否喝酒` 字段隐藏，并带停用说明。
- `客户状态` 默认 `活跃`，可选 `长期未联系`。
- 联系人列表默认展示 `活跃/待维护/长期未联系`，不默认展示 `失联/离退休/无效`。
- 选择联系人记录拜访时，自动带出联系人关联单位。
- 联系人详情顶部突出展示手机号、工作电话、微信号。
- 联系人详情基本信息 Tab 中，基础信息展示办公地点；办公习惯模块只展示 `是否抽烟`、`是否喝酒`。
- 普通员工可见四/五星联系人列表摘要，但打不开详情。
- 普通员工看不到全量线索管理入口，直达线索管理页也会被拦截。
- 普通员工仍能在首页看到与自己相关的线索。
- 页面无报错、无空白、无 `undefined/null`。

## 7. 后台待确认事项

- 原生表单删除权限由后台手动配置。
- 自定义数据清空维护页已限制为高层角色可进入，仍建议后台隐藏该导航入口。
- 宜搭导航中全量线索管理入口建议对普通员工隐藏。
- 表单数据权限建议按高层/管理层/普通员工三类角色补齐，避免只依赖前端入口。
- 字段级脱敏权限如需强制生效，应在宜搭后台同步配置。
- 半年未联系定时自动化需确认执行频率、执行时间和历史数据首轮处理范围。
